## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Razorpay Payment Integration

The project now includes Razorpay Test Mode payment support. See `RAZORPAY_SETUP.md` for setup and execution instructions. Keep the real/test secret in `.env`; never commit it.
